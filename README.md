# 📰 GenLayer News Oracle

A decentralized News Verification Oracle built on the **GenLayer Intelligent Trust Network**. This dApp allows users to verify the authenticity of news headlines using decentralized AI consensus.

---

## 🌟 Overview
In an era of misinformation, the **GenLayer News Oracle** provides a trustless layer for news validation. By leveraging GenLayer's intelligent contract capabilities, this project demonstrates how AI and blockchain can collaborate to cross-reference headlines and determine their validity.

## ✨ Key Features
- **Instant Verification:** Users can input any news headline for real-time validation.
- **AI-Powered Consensus:** Simulates the GenLayer Intelligent Trust Network's decision-making process.
- **Modern UI/UX:** A clean, responsive interface built with React and Tailwind-style aesthetics.
- **Secure & Robust:** Built with TypeScript for enhanced type safety and reliability.

## 🛠️ Technical Stack
- **Frontend:** React 18 (TypeScript)
- **Build Tool:** Vite
- **Icons:** Lucide React
- **Deployment:** Vercel (Optimized Production Build)
- **Network Architecture:** Inspired by GenLayer's Intelligent Trust Network
